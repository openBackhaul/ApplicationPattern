# Telefónica's API-Gateway Reference Guide for the MW-SDN Domain

Welcome to the **MW-SDN API-Gateway reference guide**.  
This guide centralizes all the information needed for publishing, managing, and consuming APIs of the MW-SDN-Domain within Telefónica's **API Management (WSO2)** platform.

The goal is to provide a single, structured framework combining:

- **Processes, roles, and responsibilities** 
- **Technical Capiblities and Use Cases**: What the API Management Platform has to offer for management and control of your APIs
